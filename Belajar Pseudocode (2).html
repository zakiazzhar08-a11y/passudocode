    Panduan struktur
    

    PROGRAM NamaProject
KAMUS
  a, b : integer
  hasil : integer
ALGORITMA
  input(a, b)
  hasil = a + b
  output("Hasil =", hasil)
ENDPROGRAM
    

    PROGRAM memberi nama project. KAMUS berisi deklarasi variabel dengan format nama : tipe; tipe yang dikenal: integer, real, string, boolean, char. ALGORITMA berisi input(...), output(...), dan penugasan memakai = (tanda <- juga diterima). Perbandingan memakai ==. Argumen output dipisah satu spasi secara otomatis, seperti Println di Go. Perulangan dan percabangan juga didukung: for i <- 1 to k do ... endfor, while kondisi do ... endwhile, dan if kondisi then ... else ... endif. Program diakhiri ENDPROGRAM. Komentar ditulis dengan // atau {...}.
